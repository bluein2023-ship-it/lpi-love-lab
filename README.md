# LPI 恋爱压力实验室

黑粉撞色的关系体验自我探索页面，包含 40 道情境题、十维雷达图、八型画像与动态建议。

## 使用

- 在线体验：https://lpi-love-lab.bluein2023.chatgpt.site
- 离线体验：下载 offline.html，用浏览器打开。
- 本地预览：在仓库目录运行 `python3 -m http.server 8000`，打开 http://localhost:8000 。

## 文件

- index.html：页面入口
- style.css：响应式样式（已修复白底选项文字对比度）
- app.js：40题题库、公开评分规则与报告逻辑
- offline.html：无需安装的单文件版本
- docs/题库与计分说明.md：框架分析、完整题库、计算规则

答题仅保存在当前浏览器，可在答题页清除。报告支持打印及保存 PDF。

本工具根据参考报告重新设计题库与算法，未经心理测量学信效度验证，仅用于自我探索，不作心理诊断。
